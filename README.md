# serveready

> Interactive onboarding and training infrastructure for hospitality teams.

## Problem

New hospitality employees are expected to learn a large amount of
restaurant-specific information in a very short period of time.

This includes:

- Restaurant layout and table locations
- Menu items and ingredients
- Allergens
- Service procedures
- Guest interaction
- Restaurant-specific standards

Much of this knowledge is currently transferred through verbal
instructions, shadowing, documents, and trial-and-error.

ServeReady explores a more structured approach:

> Learn → Practice → Test → Track

## Product

ServeReady is a restaurant-specific onboarding platform designed
to help new hospitality employees become confident and operational
faster.

## Initial MVP

- Employee onboarding dashboard
- Interactive restaurant map
- Menu and ingredient training
- Service training
- Scenario-based guest interaction training
- Quizzes
- Employee progress tracking
- Manager dashboard

## Target Users

### Employees

New waiters, hosts, bartenders, baristas and other hospitality staff.

### Managers

Restaurant managers and operators responsible for onboarding and
training staff.

## Product Philosophy

ServeReady is being developed around real observations from
hospitality work in Budapest.

The project prioritizes solving real operational problems over
building features for the sake of technical complexity.
